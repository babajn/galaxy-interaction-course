# 本文の概念図と注記

`.tex`ファイルは`tikzpicture`だけを含み、図番号とキャプションは各章に置いています。本文から`\input{figures/tikz/ファイル名}`で読み込みます。共通設定は`../../tikz_styles.tex`です。

`figure_index.json`は各図の挿入節、図番号、本文ページ、キャプションの索引です。最終配置の章ソースが正本であり、編集でページが変わったときは索引も更新してください。新規12点、既存図の注記2点の内訳と注意点はルートの`TIKZ_CHANGES.md`にあります。

`*_annotated.tex`は既存PDFへの注記です。元の曲線・数値データはそのまま埋め込んでいます。元図のサイズや軸範囲を変更した場合には、注記の座標も確認してください。
