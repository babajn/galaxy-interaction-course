# 改訂記録と構成・スタイル照合

## 改訂の基準

- 既存原稿：`Chap01_galaxy_simulation_v1.pdf`と同版のソースZIP。
- 構成案Version 3：第1章のEuler → leapfrog → RK4 → Kepler比較、および第2〜5章のleapfrog標準化。
- スタイルガイドVersion 1.2：KDKとRK4をともに本文の主要手法とすること、力評価回数の比較、正本・Notebook管理。

構成案・ガイドは教育方針の資料であり、詳しい導出や新しい実験の数値を与えるものではありません。
その方針に沿い、既存原稿の内容を保存しながらKDKの節と比較実験を追記しました。
新しい数値表・図は、本章コードを実際に実行して得たもので、資料からの引用値ではありません。

## 旧版からの主な変更

1. 旧1.1〜1.4の中心力、成分式、単位、円軌道条件、Euler導入を維持し、学習目標と後続章への説明を更新しました。
2. 新1.5としてKDKの部分更新、3段階、2次精度、時間反転・保存系での性質、加速度の再利用を追加しました。
3. RK4は新1.6の通常節に残しました。leapfrogを実装しないとする旧囲みを削除し、他の方法だけを簡潔に紹介しています。
4. 新1.7で加速度関数を共通化し、KDKは位置・速度を分け、RK4は状態ベクトルを使う実装を示しました。
5. 軌道・エネルギー・時間刻みの図と表を3手法またはKDK/RK4の比較へ更新しました。
6. 新1.11で力評価800回の比較、100周期のエネルギー変化、手法の使い分けを追加しました。
7. 演習を7問にし、KDKの同期速度・力評価回数を確認する問題を追加しました。速度比例抵抗はRK4による発展問題として残しました。

## 数値的・物理的な表記

- 基本の円軌道：旧版と同じM=1e11 Msun、r0=10 kpc、200ステップ/周期。
- 新設の同一コスト試験：800回の積分用力評価。KDK 799ステップ、RK4 200ステップ。
- 新設の長時間試験：100周期、100ステップ/周期。単純な円軌道を維持し、第2章の楕円軌道へ先行しません。
- 200ステップの力評価：Euler 200、KDK 201、RK4 800。独立試験では実際の関数呼び出し数で確認しています。
- 「同じ刻み」と「同じコスト」を明確に分けました。同一コストでRK4の位置誤差が小さいという実測結果もそのまま示します。
- KDKがエネルギーを厳密に保存する、あるいは速度依存力にはRK4以外が使えないとは書いていません。
- シンプレクティック性の説明は、本章の静的・滑らかなHamilton系と固定刻みに範囲を限定しています。
- 動力学的摩擦は衛星銀河・銀河中心に加え、質量ゼロのテスト粒子自体に加えないことを後続章の説明にも明記しました。

## 参照した理論

旧版と同じProject内の参考書を使い、本文末に対応箇所を示しています。

- 杉浦洋『数値計算の基礎と応用［新訂版］』第11章：Euler法、Runge--Kutta法と誤差。
- 幸谷智紀『Python数値計算プログラミング』第13章：PythonによるEuler法・中点法・古典的RK4の実装例。

物理式の初等的な変形は章本文で説明し、RK4の一般の次数条件やシンプレクティック性の証明は専門書に譲っています。
