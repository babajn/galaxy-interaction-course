# 執筆・検証メモ：第5章 v1.0

## 参照した構成と既存章

構成案Version 4とスタイルガイドVersion 1.3に従い、重力のみの主計算にKDK leapfrogを使います。
第1章の積分器、第2章の重心・相対運動、第3章のPlummer場、第4章の数CDF・逆補間・円盤生成を統合しました。
線形補間や台形則は既習事項なので、導出を繰り返さず使用箇所を示しています。
二分法は学習済みですが、この標準初期条件はエネルギーと角運動量から直接求まるため、求根を無理に挿入していません。

物理の参照箇所はBinney & Tremaine (2008)のPlummerモデルとleapfrog、Ryden (2025) §4.1の潮汐力です。
引用資料の図を転載せず、図はすべて本章の計算から生成しています。
本文末に、参考図書から学ぶ一般的な内容と、本章で設定した有効モデル・診断量・実験条件の区別を記しています。

## 本章で明示的に採用した近似

1. 星の受ける重力は、各銀河のスケール長a_kを使う二つのPlummer場の和です。
2. 中心同士は共通のbを使う有効対ポテンシャルで動きます。正確な拡がったPlummer球同士の相互力と同一視しません。
3. 標準例だけは a1=a2=b=3 kpc です。この場合、相手の場を中心位置で評価した値と中心間力が一致し、潮汐差の説明が直接成り立ちます。一般のa_k,bではその一致を仮定しません。
4. 両円盤は孤立時の円運動を与えた初期条件であり、有限距離に置いた二銀河系の厳密な平衡分布ではありません。
5. 中心軌道への星からの反作用はありません。中心の保存量と、星の時間依存場中のエネルギー変化を区別します。
6. KDKを全行へ同期して適用しますが、この一方向結合系全体を有限質量の自己無撞着N体系やその正準シンプレクティック写像と呼びません。

これらは元の教材計画を具体化したモデル選択で、参考図書がこのパラメータの銀河相互作用を定量的に保証しているという意味ではありません。

## 数値設定の変更と根拠

第4章では、固定場中の孤立円盤に0.2 Myrを採用しました。
本章でも当初0.2 Myrを試したところ、中心軌道と外側粒子割合は比較的安定でも、一部の粒子位置に時間刻み依存が残りました。
そのため、標準を0.05 Myrに変更し、0.2、0.1、0.05、0.025 Myrを同じ初期配列・同じ終時刻で比較しています。

共通151時刻で測った粒子位置の最大差 / Rdは、隣接する刻み対で順に0.251267、0.0640577、0.0160964です。
差の比が約4へ近づくことを確認していますが、これを全粒子の真の軌道誤差の上限とはしていません。
最も細かい刻み対でも最大差は約0.0483 kpcです。一方、全粒子・全評価時刻にわたる二乗平均平方根の差はRd単位で1.68e-4です。
少数の敏感な軌道と、分布全体の診断を分けて記述しました。

30 kpcより外側の割合は、このseed・閾値では全4計算で0.425、0.432でした。
閾値を越えたかどうかだけを数える指標が一致しても、各粒子位置が同じ精度で一致するとは限りません。
図の外観や中心エネルギーだけで計算全体の精度を判定しない教材上の例にしています。

## コードとデータの継承

円盤生成は第4章と同じ `rng.random((N, 2))` を使います。
一つのseed42生成器から銀河1、銀河2の順に標本化し、銀河ごとに同じseedへ戻しません。
初期の試作コードと乱数の呼び出し方が異なるため、同じseedでも昔の試作図と個々の粒子は一致するとは限りません。
配布する `data/interaction_initial.npz` を本章の初期標本の記録とします。

`origin` は出身番号です。途中で近い中心に振り分け直さず、力計算の選択にも使いません。
速度を逆転する発展演習では、銀河中心の並進速度ではなく円盤内部の速度を反転します。
恒星円盤やダークハローが変形する自己無撞着な合体計算の結論へ一般化しません。

## 検証と未実施範囲

完成版の15コードセルを実行し、独立試験93項目を通過しました。
独立試験には、標準とは異なる不等質量・異なるPlummerスケール、力の数値微分、中心のみの計算、中心力の保存量、保存頻度独立性、時間反転、等速並進した孤立円盤が含まれます。
本文図・表は標準計算の出力です。試験用の条件を本文の標準値へ混ぜていません。

ライブN体計算との比較、観測銀河のフィット、厳密なPlummer球間力の積分、自己重力円盤の安定性解析、動力学的摩擦を含む発展モデルの再検証は、本章では行っていません。
これらを実施済みと解釈しないでください。
