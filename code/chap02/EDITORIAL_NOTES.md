# 編集・検証メモ：第2章 初稿v1.0

## 設計の根拠

構成案v3の第2章は、KDKによる2体運動、重心と相対座標、円・楕円・放物線、
全エネルギー・全角運動量・重心の確認を中心にします。
スタイルガイドv1.2に従い、理論を網羅せず、物理 → 数式 → 実装 → 確認の順で展開しました。
第1章改訂v2.0のKDKと配列規約を再利用し、RK4の導出・再実装は繰り返していません。

## 学習資料と今回の数値実験を区別する

基本式の出典：Barbara Ryden, Celestial and Stellar Dynamics (2025),
§1.2 pp.4–9, §1.3 pp.9–15。プロジェクトのPDFで該当ページを確認しました。
KDKの解説の参照先：Binney & Tremaine (2008), §3.4.1 p.200、および本教材第1章。
原典の図や本文は転載せず、図は全て本章の実行結果から生成しました。
Rydenの相対位置・相対速度・換算質量は、本書の規約に合わせてD, U, m_redと表記しています。

質量、距離、刻み、パラメータ実験と演習の数値条件は、本教材用の新しい設定です。
元の輪講用教科書が同じ数値条件を指定しているという意味ではありません。

## 第1章から変更した箇所

- 中心固定の1粒子から、両方が動く有限質量の2粒子へ変更。
- 加速度関数をacceleration_keplerからacceleration_two_bodyへ変更。
- KDKの最後の引数名をmuからmassesへ変更。更新算法・加速度の再利用は同じ。
- prepare_historyの形の確認を(1,4)から(2,4)へ変更。
- 相対運動ではmu = G(M1+M2)。換算質量m_redとは明確に区別。
- 診断は比エネルギーだけでなく、2体系全体のエネルギー・運動量・角運動量へ拡張。
- 放物線ではE(0)=0なので、エネルギー誤差は初期の粒子対ポテンシャルの大きさで規格化。

## 理論・数値上の注意

本章は点質量2体の厳密なNewton重力を使う比較問題で、Plummer球の相互作用ではありません。
第5章に移る際には中心間重力のモデルと軌道初期条件をそろえて変更します。
動力学的摩擦、円盤のテスト粒子、自己重力銀河は今回の範囲外です。

3軌道の比較は同じTcまで、同じ1000ステップで計算します。
楕円の収束試験だけは解析的な1周期Tellを終点として使います。この違いを本文・表・Notebookに明記しました。
円は全出力時刻での最大位置誤差、楕円は解析的周期後の戻り位置の誤差です。
それらを同じ意味の誤差として扱ったり、定義の違いを隠して大小を比較したりしません。

近点距離は保存時刻から得た最小値です。連続時間の近点とは限らず、時間積分誤差と出力の時間サンプリングを
区別しています。近点時刻の求根・高次補間は先取りせず、囲みで方法の名前を紹介するだけにしました。

移動する重心では全エネルギーの符号だけで束縛性を判断しません。相対運動のepsilonを使います。
全エネルギー・角運動量の分解式は、非零重心速度・任意原点の独立試験でも確認しています。
